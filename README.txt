POSTHOG FLASHCARDS

The flashcards are an interactive web page, not a regular text document.

PHONE
1. Extract this ZIP in Files / Downloads.
2. Tap index.html.
3. Choose Chrome, Safari, or another web browser if asked.

DESKTOP
1. Extract the ZIP.
2. Double-click index.html.

The page works offline. Progress is saved locally in that browser.
Telegram's document preview may display the HTML source instead of running the page; download and open it in a browser.
